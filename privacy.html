마이플래너 개인정보처리방침

최종 수정일: 2026년 9월 5일

마이플래너(이하 "본 앱")는 개발자 본인이 개인 일정·일기·운동 기록을 관리하기 위해 만든 개인용 웹 앱입니다. 본 문서는 본 앱이 어떤 정보를 다루는지 설명합니다.

1. 수집하는 정보

  • 사용자가 직접 입력한 내용 — 할 일, 일기, 사진, 운동 기록, 걸음 수
  • 구글 계정 정보 — 사용자가 구글 캘린더 연동에 동의한 경우, 캘린더 일정을 읽기 전용으로만 가져옵니다 (calendar.readonly 권한)

2. 정보의 이용

수집된 정보는 오직 사용자 본인에게 일정과 기록을 화면에 보여주기 위해서만 사용합니다. 광고, 분석, 프로파일링, 머신러닝 학습 등 다른 목적으로 이용하지 않습니다.

3. 구글 사용자 데이터 처리

  • 구글 캘린더 일정은 사용자의 브라우저에서 직접 구글 API를 호출해 가져오며, 별도의 서버에 저장하거나 전송하지 않습니다.
  • 인증 토큰은 사용자의 브라우저 저장소(localStorage)에만 보관됩니다.
  • 구글 사용자 데이터를 제3자에게 판매하거나 공유하지 않습니다.
  • 본 앱의 구글 사용자 데이터 이용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

4. 정보의 보관

사용자가 입력한 할 일·일기·사진 등의 기록은 Supabase가 제공하는 데이터베이스에 저장되며, 계정 소유자 본인만 접근할 수 있도록 행 수준 보안(RLS)이 적용되어 있습니다.

5. 연동 해제 및 삭제

  • 앱 내 "연동 해제" 버튼으로 언제든 구글 캘린더 연동을 끊을 수 있으며, 저장된 토큰은 즉시 삭제됩니다.
  • 구글 계정 권한 페이지에서도 본 앱의 접근 권한을 철회할 수 있습니다.
  • 앱 내에서 개별 기록을 삭제할 수 있습니다.
